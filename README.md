# قرآن (تسبيع)

A free, non-profit app for reading the whole Quran every week, the way the Companions divided it:
seven hizbs of complete surahs (فمي بشوق), one a day, each split across the five prayers.

- Madinah mushaf (King Fahd Complex, 1421H print), drawn with the Complex's own page fonts, unmodified.
- Every page is built and checked by `scripts/build_quran.py` (6,236 verses, 77,429 words).
- The narrations on the "idea" page are in `src/quran/idea.ts`, each with its source.
- Android package `com.tasbee.quran`. Expo SDK 58.

This folder is self-contained so it can move to its own repository as is.
